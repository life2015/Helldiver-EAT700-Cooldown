# 火次抛燃烧弹头增加近炸并且减CD到标准次抛

基于原来的纯减 CD 版，固定使用原版 EAT-700 燃烧弹头，加上近炸引信，无模式切换。
保持原版弹药编号、直击爆炸载荷、伤害、弹速与外观，不换用 RL-77 空爆弹药。
近炸参数参考原生 Flak：检测半径 2 米、触发延迟 0.2 秒、引信启动距离 1 米。
起爆角度上限和近炸检测筛选采用原生 Flak 参数；近炸及碰撞均使用原版燃烧载荷。
起爆角度放宽到 360°，因此也放宽了原生碰撞时的起爆角度限制。
基础 CD 70 秒，当前 5% 与 10% 舰船升级后约 59.85 秒，取整约 60 秒。

2026-09-23 用户确认 0.2.1 本地近炸燃烧版完成并要求打包。本地使用 v15 渠道；v14 有离线加载测试，实机与联机未单独验证。

## 安装

见 [INSTALL.txt](INSTALL.txt)。提供 v14 内置加载器、v15 需另装加载器两个渠道，二选一。
替换旧纯减 CD 版；不能与“火次抛使用空爆弹头并且减CD到标准次抛”同时启用。

## 实现和验证

仅对原生燃烧弹丸记录修改六个 4 字节引信字段，并修改一个 4 字节冷却字段。
校验完整弹丸定义哈希、记录身份、字段原值、原生函数签名和游戏版本。
两部分先完成校验，再执行事务；失败时只还原本模组仍持有的字段。
不新增弹药编号，不改武器菜单，不替换配置表指针，不写可执行代码。

适配 Steam build 25327279 / EXE 1.8.45850.0。
需要 Windows x64、Python 3、本机游戏 bin/lua51.dll，可通过 HD2_GAME_ROOT 设置游戏目录。

```powershell
python scripts/test.py
python scripts/build.py
```

构建会缓存并校验固定版本的官方 v14/v15 加载器，用于包装和离线启动测试。
ZIP 输出在 releases/，构建摘要在 build/package-matrix.json。
纯减 CD 的旧版本仍保存在历史安装包中。

0.2.1 修复：0.2.0 遗漏了起爆角度上限，原生 60° 上限拒绝了游戏按 90° 处理的近炸命中；同时补齐近炸查询筛选参数。分析见 [docs/proximity-fix.md](docs/proximity-fix.md)。
